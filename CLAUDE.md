# Guardrails

1. **Never spend credits on any other app or service without asking me first.**
   Before any action that could cost money or use up credits/quota outside this
   conversation, stop and ask for approval, saying which service it is and
   roughly what it will cost. That covers paid APIs (via curl, SDKs or CLIs),
   cloud resources (GCP `gcloud`/`bq`/`gsutil` and similar), starting new
   cloud sessions, scheduled tasks or multi-agent workflows, extended web
   searches, and signing up for or buying anything. When unsure, ask.

2. **Never connect to any other app or service without my consent.**
   Ask before connecting to anything new, and wait for a clear yes. That
   covers adding connectors or MCP servers, attaching repositories or my
   computer's folders, signing in or authorizing (OAuth, API keys, tokens),
   opening SSH connections, registering webhooks, messaging other sessions,
   fetching web pages, and reading from or writing to already-connected apps
   such as Google Drive. GitHub access to this repository is already approved.
